Kimi: # 한문 고전 번역 앱 PRD (Product Requirements Document)

## 1. 제품 개요

### 1.1 제품명
**「한문독해」** (가칭) — 한문 구절을 영어 구문독해 방식으로 풀이하고, 관련 고사성어와 번역 방법론을 함께 제공하는 학습 앱

### 1.2 제품 비전
> "한문이 어려운 사람도, 영어 구문독해하듯 단계별로 한문을 풀어낼 수 있게 한다."

### 1.3 타겟 사용자
| 세그먼트 | 설명 |
|---|---|
| 고등학생 | 수능 한문, 문학 과목 대비 |
| 대학생 | 한문 강의 보조 학습 |
| 일반인 | 한문 고전에 대한 호기심 충족 |
| 한문 교사/학원 강사 | 수업 자료 및 풀이 참고 |

## 2. 핵심 기능 정의

### 2.1 기능 1: 구문독해식 한문 풀이 (Core Feature)
사용자가 한문 구절을 입력하면, 영어 구문독해와 유사한 방식으로 **단계별 분석**을 제공한다.

**출력 형식:**
```
📌 원문: 學而時習之, 不亦說乎

① [단어 분해]
   學(학습하다) + 而(그리고) + 時(때때로) + 習(익히다) + 之(그것을)
   
② [어순 재구성]
   → [學(배운 것)을 時(때때로) 習(익히)而(하고)] 不亦(어찌 ~하지 않으랴) 說(기쁘)乎(가)
   
③ [현대어 해석]
   "배운 것을 때때로 익히면, 기쁘지 않겠는가?"
   
④ [영어 번역]
   "Is it not a pleasure to practice what you have learned at due times?"
```

### 2.2 기능 2: 번역 방법론 가이드
해당 구절을 번역할 때 적용된 **번역 기법과 방법론**을 함께 설명한다.

**출력 예시:**
```
📖 번역 방법론 적용

▸ 도치(倒置) 복원: "學而時習之"는 '학습하고 때때로 익힌다'가 아니라
  '배운 것을 때때로 익힌다'로 해석 (목적어 '之'의 도치)
  
▸ 의문문 전환: "不亦...乎" = "어찌 ~하지 않으랴" (긍정적 의문 = 강한 긍정)
  
▸ 생략 복원: 주어 생략 → 문맥상 '나(孔子)' 또는 일반화된 주체로 해석
```

### 2.3 기능 3: 연관 고사성어 & 문장 추천
입력한 구절과 **의미적·어휘적으로 연관된 고사성어**와 **유사한 명문구**를 추천한다.

**출력 예시:**
```
🔗 연관 고사성어

▸ 溫故知新 (온고지신)
   - 출전: 《논어》為政
   - 의미: 옛 것을 익혀 새 것을 앎
   - 연관성: '學而時習'과 같은 학습의 지속성 강조

▸ 學而不思則罔 (학이불사즉망)
   - 출전: 《논어》為政
   - 의미: 배우되 생각하지 않으면 막연함
   - 연관성: '學'이라는 동일 키워드, 학습 방법론 대비
```

### 2.4 기능 4: 한문 입력 보조
- **한자 자동 완성**: 한글 음을 입력하면 한자 후보 제시
- **한자 음·뜻 팝업**: 터치/클릭 시 한자의 음(音), 뜻(訓), 부수, 총획수 표시
- **클립보드 붙여넣기**: 웹/책에서 복사한 한문 바로 입력

6. **문맥적 해석** — 출전과 전후 문장을 고려한 의미 확정
7. **현대어 번역** — 의역과 직역의 균형 맞추기

## 2. 핵심 기능 정의 (추가)

### 2.5 기능 5: 부수 기반 한자 암기 (신규)
입력한 한문 구절에 포함된 한자들의 **부수(部首)**를 분석하고, 같은 부수를 가진 한자들과의 **의미적·형태적 연결망**을 암기 카드 형태로 제공한다.

**출력 형식:**
```
🧩 부수 암기 네트워크

【學】
  ├─ 부수: 子(자, 아이)
  ├─ 부수 의미: 자식, 배움의 대상/주체
  ├─ 같은 부수 한자:
  │   ├─ 字(글자) — 아이(子)가 집(宀)에서 배우는 것
  │   ├─ 孝(효도) — 아이(子)가 노인(耂)을 섬김
  │   ├─ 孤(고아) — 아이(子)가 홀로(瓜) 있음
  │   └─ 存(존재) — 아이(子)가 재(才)간에 있다
  └─ 암기 팁: "子(아이)가 배우는 것이 學(학습)"
  
【習】
  ├─ 부수: 羽(우, 깃털)
  ├─ 부수 의미: 날개, 새의 깃
  ├─ 같은 부수 한자:
  │   ├─ 翔(비상하다) — 날개(羽)로 양(羊)처럼 높이 날다
  │   ├─ 翻(뒤집다) — 날개(羽)로 번(番)히 움직이다
  │   └─ 翅(날개) — 날개(羽)를 지닌(支) 것
  └─ 암기 팁: "새가 날개(羽)로 반복해 연습(習)하듯"
```

**암기 카드 UI:**
- **앞면**: 한자 + 부수 (큰 글씨)
- **뒷면**: 부수 의미 + 같은 부수 한자 3~5개 + 암기 팁
- **스와이프**: 다음 한자로 넘기기 (플래시카드 형태)

## 부록: 부수 암기 콘텐츠 예시 (앱 내 제공)

### 예시 1: 學(학)의 부수 子(자)
> **부수 이야기**: 子는 '아이'를 뜻합니다. 옛날에는 배움의 주체가 어린 아이였기에, 배움과 관련된 많은 글자에 子가 들어갑니다.
> 
> **암기 네트워크**:
> - 學(학습): 아이(子)가 손(𦥑)으로 계산(爻)하며 배움
> - 字(글자): 아이(子)가 집(宀)에서 글을 익힘
> - 孝(효도): 아이(子)가 노인(耂)을 머리에 이고 섬김
> - 孤(고아): 아이(子)가 혼자(瓜) 남겨짐
> 
> **한 문장 암기법**: "아이(子)가 배우면(學) 글자(字)를 알고, 효도(孝)를 알며, 고아(孤)도 보살핀다."

### 예시 2: 習(익힐 습)의 부수 羽(우)
> **부수 이야기**: 羽는 '새의 날개'입니다. 새가 날개를 퍼덕이며 반복해서 연습하는 모습에서 '익히다'는 뜻이 나왔습니다.
> 
> **암기 네트워크**:
> - 習(익히다): 날개(羽)로 반복해 연습함 (白=빈틈없이)
> - 翔(비상): 날개(羽)로 양(羊)처럼 유유히 날음
> - 翻(뒤집다): 날개(羽)로 번(番)히 움직임
> 
> **한 문장 암기법**: "새가 날개(羽)를 퍼덕여 반복(習)하면 하늘을 비상(翔)한다."

## 🏗️ Phase 1: 인프라 세팅 & 데이터 설계
**목표:** Cloudflare 기반 프로젝트 뼈대를 세우고, DB 스키마와 R2 구조를 확정한다.

| 항목 | 상세 |
|---|---|
| **기술 스택** | Astro (Static Site) + Cloudflare Pages Functions |
| **인프라** | Pages 프로젝트 생성, D1 DB 생성, R2 버킷 생성 |
| **DB 스키마 (D1)** | `users`, `search_logs`, `idioms`, `radicals`, `characters`, `passages` 테이블 설계 |
| **R2 구조** | `/fonts/` (Noto Serif CJK), `/assets/` (정적 이미지), `/exports/` (사용자 PDF 저장용) |
| **CI/CD** | GitHub Repo → Cloudflare Pages 자동 배포 파이프라인 구축 |
| **산출물** | 빈 화면이지만 배포 가능한 `https://hanmun-app.pages.dev` |

```sql
-- D1 스키마 예시
CREATE TABLE search_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  original_text TEXT NOT NULL,
  result_json TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE idioms (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  hanja TEXT,
  eum TEXT,
  meaning TEXT,
  source TEXT,
  related_keywords TEXT -- JSON array
);

CREATE TABLE radicals (
  id INTEGER PRIMARY KEY,
  radical TEXT,
  name TEXT,
  meaning TEXT,
  stroke_count INTEGER
);
```

## 📚 Phase 3: 콘텐츠 레이어 — 고사성어·방법론·부수 암기
**목표:** AI 결과 외에 **구조화된 데이터** 기반 기능을 추가한다.

| 항목 | 상세 |
|---|---|
| **D1 시드 데이터** | 고사성어 500개, 부수 214개, 상용한자 1,000개 CSV → D1 일괄 삽입 |
| **고사성어 추천** | `/api/idioms?keyword=學` 엔드포인트. 입력 구절의 한자로 D1에서 `LIKE` 검색 |
| **번역 방법론 탭** | 프롬프트에서 `methodology` 필드 활용 + 프론트엔드 아코디언 UI |
| **부수 암기 (Flashcard)** | Swiper 기반 카드 UI. D1 `radicals` + `characters` 조인 쿼리로 데이터供給 |
| **연관 문장** | D1 `passages` 테이블에서 키워드 매칭 |
| **산출물** | 풀이 / 방법론 / 연관콘텐츠 / 부수암기 4개 탭이 모두 동작하는 버전 |

```javascript
// Pages Functions 예시: 고사성어 검색
export async function onRequestGet(context) {
  const { env } = context;
  const url = new URL(context.request.url);
  const keyword = url.searchParams.get('keyword');
  
  const stmt = env.DB.prepare(
    'SELECT * FROM idioms WHERE hanja LIKE ? OR related_keywords LIKE ? LIMIT 5'
  ).bind(`%${keyword}%`, `%${keyword}%`);
  
  const results = await stmt.all();
  return Response.json(results);
}
```
